## Features

### Design
- Pixel-perfect reconstruction of reference image
- Elegant cream and black color scheme with gold accents
- Cormorant Garamond & Montserrat typography
- Custom scroll animations
- Parallax effects
- Premium hover interactions

### Functionality
- Fully responsive (mobile-first)
- Smooth scroll navigation
- Mobile hamburger menu
- Contact form with validation
- Lazy loading images
- Scroll-triggered animations

### WhatsApp Integration
- Floating WhatsApp button on ALL pages
- Pre-filled message: "Hello, I'd like to know more about your services."
- Phone number: 919999999999 (editable)
- Pulsing animation for visibility
- Tooltip on hover

### Pages
1. **Home** - Hero, tagline, about preview, services, process
2. **About** - Company story, team members
3. **Services** - Detailed service cards with features
4. **Portfolio** - Gallery grid with hover overlays
5. **Packages** - Pricing tiers (Essential, Premium, Luxury)
6. **Contact** - Contact form + WhatsApp CTA

## Technical Details
- Pure HTML5, CSS3, JavaScript (no frameworks)
- CSS Grid & Flexbox layouts
- CSS Variables for theming
- Intersection Observer API for animations
- Mobile-optimized navigation
- SEO meta tags
- Accessible (ARIA labels, semantic HTML)

## Browser Support
- Chrome, Firefox, Safari, Edge (latest versions)
- Mobile: iOS Safari, Chrome Mobile

## Setup
1. Replace placeholder images in `assets/images/`
2. Update WhatsApp number in all HTML files
3. Update contact details in footer
4. Deploy to web server

## Customization
- Colors: Edit CSS variables in `:root`
- Fonts: Change Google Fonts link in HTML `<head>`
- WhatsApp: Update `919999999999` in all pages
- Content: Edit text in HTML files
