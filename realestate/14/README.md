
# Luxury Real Estate Website

A premium, production-grade luxury real estate website built with mobile-first design principles.

## Features

- **4 Complete Pages**: Home, About, Services, Contact
- **Dark Luxury Theme**: Black backgrounds with gold accents
- **Mobile-First**: Fully responsive from 320px to 4K
- **WhatsApp Integration**: Floating button on every page
- **Lead Generation**: Contact forms, CTAs, conversion optimized
- **Performance**: Lazy loading, optimized animations, efficient CSS
- **Accessibility**: ARIA labels, semantic HTML, keyboard navigation

## Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero, About, Services, Showcase, Stats, Gallery |
| About | `about.html` | Company story, Mission, Team, Stats |
| Services | `services.html` | Service details, Property types, CTA |
| Contact | `contact.html` | Contact form, Info, Map |

## Tech Stack

- HTML5 (Semantic)
- CSS3 (Variables, Grid, Flexbox, Animations)
- Vanilla JavaScript (ES6+)
- Google Fonts (Playfair Display + Inter)
- SVG Icons (Inline)

## WhatsApp Configuration

Edit the phone number in the WhatsApp floating button:
```html
<a href="https://wa.me/919999999999?text=...">
```

Replace `919999999999` with your business number.
